# Construction_Defect_Complaint_System
AI를 활용한 건설하자 민원 응대 및 관리 시스템  v-0.1
TEAM 안전제일

gpt-4o API를 사용하여 이미지 업로드후 AI 가 분석하여 하자 유형을 다음과 같은 5가지의 항목으로 나타냅니다.
1. 하자의 유형
2. 하자의 심각도 (1~10점)
3. 하자 예상 보수 비용
4. 하자 처리 방법
5. 관련 법규

회원 가입후 사용자, 관리자 권한으로 분리하여 민원 관리가 가능합니다.

사용자 - 하자 분석 요청 및 민원 접수,처리 현황조회 기능 구현
관리자 - 등록된 민원의 처리상태 조회 및 변경 기능 구현
